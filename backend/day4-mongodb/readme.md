Q1. MongoDB aur Mongoose me difference?
Answer:
MongoDB = Database
Mongoose = MongoDB ko Node.js se connect aur manage karne wali library

Q2. Schema kya hota hai?
Answer:
Data ka structure define karta hai.

Q3. Model kya hota hai?
Answer:
Schema ke basis par database operations karne ke liye use hota hai.

Q4. User.create() kya karta hai?
Answer:
Database me new document insert karta hai.

Q5. .env kyun use karte hain?
Answer:
Sensitive data (DB URL, passwords, API keys) ko code se alag rakhne ke liye.
